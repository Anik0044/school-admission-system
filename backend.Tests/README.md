# School Admission System

A comprehensive online school admission system built with **.NET 8 (C#)**, **React 18**, **PostgreSQL**, and **Docker**.

## 🚀 How to Run the Application

Ensure you have **Docker Desktop** installed and running on your machine. You do not need to install .NET, Node.js, or PostgreSQL locally.

1. Open a terminal in the root directory (where `docker-compose.yml` is located).
2. Run the following command:
   ```bash
   docker compose up --build -d
